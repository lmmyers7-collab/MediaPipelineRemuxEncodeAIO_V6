`NO_CORE_TO_DESKTOP` dependency-boundary cleanup. The implementation plan lives
in `README.md`; this file records the Phase 0 baseline, ownership decisions,
compatibility export expectations, allowlist actions, implementation evidence,

  only for their remaining record families, such as `AuditRecord`,
  `CompletedJobRecord`, `FailureRecord`, `QueueRecord`, `Snapshot`, or
  `TelemetrySnapshot`.

  domain-owner move does not add new package-cycle allowlist debt.

fields, state-file paths, media policy, publish/drain behavior, rename behavior,
and source/scratch/output behavior are unchanged.

## Ledger Schema

Grouping rule: one row may group multiple imported symbols only when they share
the same source module, target module, source path, and import line. Separate
import statements or unrelated target modules are separate rows.

Required statuses are `open`, `migrating`, `migrated`, or `blocked`. Phase 0
uses `open` for allowlisted legacy debt and `blocked` for dirty-tree imports
owned by other packets.
