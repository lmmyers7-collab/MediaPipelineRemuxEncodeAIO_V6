# UI Reference Policy

Keep project-specific UI decisions and implementation notes in repository-owned
Markdown. Do not commit Office working documents under `docs/`; binary document
formats obscure reviewable provenance and are distributed in Git clones and
source archives even when portable-release policy excludes them.

For general interface-design background, use the official
[Refactoring UI](https://refactoringui.com/) site. Do not copy paid or otherwise
restricted third-party material into this repository without an explicit,
reviewed redistribution permission record and a corresponding source-intake
policy exception.
