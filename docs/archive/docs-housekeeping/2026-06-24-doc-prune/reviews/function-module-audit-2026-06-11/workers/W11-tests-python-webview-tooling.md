## Detailed Findings

### W11-001 - Browser smoke skips can pass release validation

- Severity: Medium
- Location: `tests/webview/test_webview_browser_completed_pending_proof_smoke.py:576`, `tests/webview/test_webview_browser_completed_pending_proof_smoke.py:613`; representative of the assigned `tests/webview/test_webview_browser_*` browser-smoke group.
- Problem: Browser-backed tests call `self.skipTest(...)` when Node or a browser executable is unavailable. The adjacent release wrappers invoke these unittest modules directly, where skipped tests still produce a successful process exit unless the wrapper adds its own requirement check.
- Impact: A release/test run can appear to include WebView browser proof while actually executing zero browser coverage on machines missing Node, Chrome, or Edge.
- Evidence: Source review found prerequisite skips in the completed/pending-proof smoke and the same pattern by search across multiple assigned browser smoke modules. The release script references WebView browser smoke wrappers as release checks, and those wrappers delegate to `python -m unittest`.
- Fix direction: Add a release-mode requirement, for example an environment flag or wrapper argument that converts missing browser prerequisites into hard failures for release gates while keeping optional skips for local developer runs.
- Validation: Run a WebView browser smoke wrapper with Node/browser intentionally unavailable and verify nonzero exit in release-required mode; run the same wrapper with prerequisites installed and verify the browser-backed assertions execute.

### W11-002 - No-mutation support misses image subtitle sidecars

- Severity: Medium
- Location: `tests/webview/webview_browser_smoke_support.py:_MEDIA_NO_MUTATION_SUFFIXES`
- Problem: The media no-mutation snapshot watches video, text subtitle, manifest, and JSONL suffixes, but it does not include `.idx`, `.sub`, or `.sup`.
- Impact: The project treats subtitle preservation and image-subtitle conversion as high-risk behavior. A smoke that claims no media mutation can miss VobSub/PGS-style subtitle sidecar changes under a watched fixture root.
- Evidence: Full-source review of `webview_browser_smoke_support.py` showed the fixed suffix allow-list. Full-source review of `tests/python/desktop/test_browser_smoke_support.py` showed coverage for watched/unwatched behavior but no image-subtitle sidecar cases.
- Fix direction: Extend the watched suffix set or derive it from the subtitle sidecar policy used by the pipeline; add unit cases that prove `.idx`, `.sub`, and `.sup` creates/modifies/deletes are detected.
- Validation: Add a temp fixture containing those suffixes and assert `assert_media_no_mutation` fails on creation, deletion, and content change.

### W11-003 - Dependency atlas cleanup can delete unrelated root artifacts

- Severity: Medium
- Location: `src/mediapipeline/tools/dev/generate_dependency_atlas.py:clean_outputs`
- Problem: `clean_outputs()` removes root-level files matching broad legacy patterns such as `*python_dependencies.png`, `*python_dependencies.svg`, `*dependency_domains.png`, and `*dependency_domains.svg`.
- Impact: A developer running atlas generation can lose unrelated root artifacts whose names happen to match the stale-output pattern.
- Evidence: Full-source review of `generate_dependency_atlas.py` found the broad `REPO_ROOT.glob(...)` cleanup. Full-source review of `tests/python/tooling/test_dependency_atlas.py` found tests for import edge collection and missing Graphviz handling only, not cleanup confinement.
- Fix direction: Restrict cleanup to exact generated filenames, a manifest of owned outputs, or files carrying an atlas-generated marker; add a cleanup safety unit test around unrelated matching files.
- Validation: Patch `REPO_ROOT` to a temp directory, create both owned and unrelated matching files, run cleanup, and assert unrelated files remain.

### W11-004 - Release finalize lacks failure/rollback coverage

- Severity: Medium
- Location: `src/mediapipeline/tools/change_control/finalize_release.py:_finalize`; coverage gap in `tests/python/tooling/test_change_control.py`
- Problem: `_finalize` mutates release state before invoking generator scripts, but the assigned tests do not cover generator failure after those mutations.
- Impact: If index/changelog/manifest generation fails, the working tree can be left with version and packet state partially finalized, requiring manual repair and weakening change-control trust.
- Evidence: Full-source review of `finalize_release.py` showed the mutation order. Full-source review of `tests/python/tooling/test_change_control.py` found only channel/exposure coverage for finalize, not failure behavior.
- Fix direction: Either run failure-prone generators before destructive packet moves, stage updates atomically, or implement rollback. Add tests that monkeypatch generator execution to fail and assert source packet, target packet, and version state are consistent.
- Validation: Targeted unit tests in `tests/python/tooling/test_change_control.py` for dry-run and post-mutation generator failure.

## Test Coverage Gaps

- Browser-smoke prerequisite handling is not release-strict. Current assigned tests can skip browser execution and still produce a green unittest result.
- `tests/python/tooling/test_dependency_atlas.py` does not cover cleanup safety for generated/stale atlas outputs.
- `tests/python/tooling/test_change_control.py` does not cover `finalize_release._finalize` rollback/failure behavior or a no-mutation dry-run contract for release finalization.
- `tests/python/desktop/test_browser_smoke_support.py` covers selected watched and unwatched suffix behavior but does not include image subtitle sidecar suffixes.
- Search-only review found many assigned `tests/webview/test_webview_browser_*` modules stubbing `window.apiPost`. That is useful for UI branch tests, but it does not prove real backend route, command-journal, or persistence behavior unless paired with route-level tests.

## Boundary Risks

- WebView smoke support is intended to protect runtime/media state, but its current no-mutation surface is suffix-based and incomplete for image subtitle sidecars.
- Browser smokes frequently isolate UI behavior with mocked API calls. This limits runtime mutation risk during tests, but it can also create false confidence that backend-owned media policy and command-journal behavior were exercised.
- Developer tooling cleanup in `generate_dependency_atlas.clean_outputs()` can mutate repository-root artifacts outside a manifest of owned outputs.
- Change-control release tooling mutates version and packet files. Failure ordering needs stronger tests because this repo relies on the change ledger as a release-critical control.
