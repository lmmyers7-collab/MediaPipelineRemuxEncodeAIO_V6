## Recurring Patterns

- **Boundary count is high**: Python, PowerShell, WebView, Tauri, JSON files, SQLite mirrors, generated schemas, and operator docs all carry overlapping truth.
- **Safety is present but expensive**: many guardrails exist, but they rely on running the right wrapper, reading the right warning, or preserving the right change packet.
- **Distributed worker mode is the riskiest new frontier**: claim identity, done durability, path maps, lifecycle stop, stale recovery, and result evidence all have high-cost failure modes.
- **Media policy parity is fragile**: Python previews and PowerShell runtime both model decisions; audio/subtitle reviews already show concrete drift.
- **Recovery paths lag evidence paths**: Completed/Pending reconciliation is rich in read-only evidence, while mutation repair remains design-only.
- **Operator trust can fail without media corruption**: stale command history, display filters, stopped/draining wording, and generated-summary drift can push a human toward unsafe decisions.
- **Real-media validation is the final arbiter**: many tests are synthetic, static, or fixture-backed; FFmpeg/subtitle/audio/publish behavior still needs representative files.

## Owner-Facing Roadmap

1. **Stabilize the workspace first**: split the 626 dirty entries into packets or discard/archive superseded review artifacts. Do not treat any current validation as release proof until this is done.
2. **Close the data-loss class**: stale partial cleanup, single-file source-root validation, network done durability, and network source identity should be fixed before broader feature work.
3. **Make network mode boring**: enforce worker ownership, durable terminal reports, strict path maps, no duplicate claim race, explicit draining states, and result-artifact parity with local workers.
4. **Reconcile media-policy engines**: build a cross-engine fixture matrix for remux/encode, size, audio, subtitles, MP4 special cases, and plan executor output.
5. **Promote recovery carefully**: implement repair/reconcile dry-runs before any mutation route, with rollback, hash/no-touch evidence, and command journaling.
6. **Tighten operator trust surfaces**: fail closed on safety-critical WebView validation drift, persist failed command exceptions, show journal durability, and make filtered hidden risks harder to miss.
7. **Make validation reproducible**: keep browser smoke prerequisites fail-closed, keep generated summaries current, and maintain a real-media sample evidence packet that future owners can rerun or recreate.
