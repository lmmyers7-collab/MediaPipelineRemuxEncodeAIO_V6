# V6 Operator UX Remediation Remaining Tasks

Created: 2026-05-28

Purpose: track the remaining operator-experience remediation work after the first backend-authored status-state pass. This is an implementation tracker, not a new product vision. It keeps the next chunks small, backend-owned, and testable.

## Authority Boundary

- Backend remains the source of truth for queue state, media policy, pending publish drain, completed output proof, diagnostics state, settings persistence, rename apply, and process control.
- WebView may render backend state, stage local filters, request documented routes, and show advisory copy.
- Do not add frontend-only filesystem mutation, publish, retry, repair, delete, settings-save, queue-write, or media-policy decisions.
- Do not fake progress, ETA, GPU/NVENC usage, validation, or recovery state. If reliable data is missing, add a minimal backend contract first.
