# Pipeline map

Generated by `python -m mediapipeline.tools.dev.generate_pipeline_map` from `src/mediapipeline/contracts/stages.py`. Do not hand-edit.

This file enumerates the canonical pipeline stages, their payload/data contracts,
stage-specific Pydantic fields, and the intended Python/PowerShell ownership
surface per ADR-0002.

## Wire contract

PowerShell-backed stages run via:

```
ops/pipeline/engine/entrypoint.ps1 -Stage <stage> -PayloadJson <json-or-path>
```

- `<stage>` is a value from `src/mediapipeline/contracts/stages.py::StageName`.
- `<payload-json>` is a `StageRequest` envelope or a path to a JSON file.
- The engine returns a `StageResult` envelope on stdout as one JSON document.
- Logs go to stderr and must not be required for result parsing.
- All payloads and results carry `schema_version: "v1"`.
- The engine rejects unknown schema versions.
- The dispatcher is orchestration-only; no Local API stage-execute route exists.
- A stage may use the PowerShell entrypoint or a narrowly registered Python executor; the backend is listed below.
- Only stages marked enabled below dispatch to behavior; disabled mutation DTOs are descriptive contracts, not future route commitments.
