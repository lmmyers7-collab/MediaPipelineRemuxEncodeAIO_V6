## What This Run Does NOT Prove

Regardless of pass or skip status, any WebView smoke run does not prove:

- FFmpeg route correctness, encode choices, or media output quality
- Subtitle OCR or SRT conversion on real files
- Audio passthrough or transcode policy on real streams
- Pending publish drain or manifest integrity on real parked outputs
- Settings persistence or config file correctness beyond the specific smoke scope
- Real-media route decisions or size-guard behavior
- Plex direct-play or streaming compatibility

For real-media validation follow `Docs/sample-validation/V5_REAL_MEDIA_VALIDATION_PLAYBOOK.md` and record evidence in `Docs/sample-validation/REAL_MEDIA_VALIDATION_EVIDENCE_TEMPLATE.md`.
