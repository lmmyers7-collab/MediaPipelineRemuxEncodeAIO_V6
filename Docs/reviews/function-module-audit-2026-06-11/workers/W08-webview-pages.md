## Detailed Findings

### W08-001 - Audit/Rerun start controls use Pipeline form state for start-decision gating

`launchButtonGate` builds the correct request for Audit and CSV Rerun, uses it for the backend preflight target gate, then discards it for the start-decision gate:

- `apps/desktop/webview/static/assets/launch/commandButtons.js:110`-`118`: Audit calls `collectAuditStartRequest()` and `launchTargetGate("audit", request, ...)`, then calls `launchStartDecisionGate(collectPipelineStartRequest())`.
- `apps/desktop/webview/static/assets/launch/commandButtons.js:120`-`128`: CSV Rerun calls `collectRerunStartRequest()` and `launchTargetGate("rerun", request, ...)`, then calls `launchStartDecisionGate(collectPipelineStartRequest())`.

Impact: the displayed enabled/disabled state for Audit and CSV Rerun can depend on unrelated Pipeline Processor mode/sleep/schedule/single-file state. This can produce stale policy inference and misleading operator guidance. The backend remains authoritative because the actual commands still post to backend routes in `launchView.js`, but the WebView gate can mislead before submission.
