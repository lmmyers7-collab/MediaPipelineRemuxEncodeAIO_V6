## Blocked Residual

`unsafe-inline` remains in the Local API and Tauri CSP. Current `index.html` uses inline bootstrap assignment, and Tauri startup also injects bootstrap state before the API client captures/scrubs the token. Removing `unsafe-inline` safely needs a separate nonce/hash or external bootstrap design that preserves the route/WebView validation contract. Safe next step: create a dedicated CSP/bootstrap redesign packet and validate it with Local API browser smoke, Tauri startup, and WebView validation tests.
