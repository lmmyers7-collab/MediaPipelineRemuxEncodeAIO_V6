## Risk of Splitting

From `CHANGELOG_NAVIGATION_PROPOSAL.md`:

| Risk | Reason |
|---|---|
| Cross-reference fragility | Addenda reference their feature entry; splitting to separate files breaks these references |
| Reader context loss | A reader following one feature benefits from seeing addenda together |
| Maintenance burden | Multiple files require format changes to propagate |
| Search scope fragmentation | A single file is searchable with one `Select-String`; multiple files require `-Recurse` |

**Recommendation**: Do not split. 250 headings is large but not problematic for Markdown load time or editor stability.
