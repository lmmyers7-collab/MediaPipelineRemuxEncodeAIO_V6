Library goal

Try remux fallback
If an automatic size/bitrate-threshold encode grows past the buffer, try safe remux/direct copy. Forced route overrides warn only and do not fallback. If remux is blocked, reject the oversized encode for review before publish.
Block publish
Stop an oversized encode before publish so it can be reviewed instead of reaching the final library.
Warn only
Record the size overage and continue when the rest of output verification passes.
