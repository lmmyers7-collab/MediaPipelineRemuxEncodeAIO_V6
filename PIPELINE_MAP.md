# Pipeline map

Generated from `app/contracts/stages.py` on 2026-05-28.

This file enumerates the nine canonical pipeline stages, their inputs
(`*Payload`), their outputs (`*Result`), and where each stage's executor
lives (per ADR-0002).

> This is intended to be auto-generated by a future
> `scripts/dev/generate_pipeline_map.py` (Phase 4). Until then it is
> hand-synced. If it drifts from `app/contracts/stages.py`, regenerate

## Wire contract

Every stage runs via:

```
engine/entrypoint.ps1 <stage> <payload-json>
```

- `<stage>` is a value from `app/contracts/stages.py::StageName`.
- `<payload-json>` is the matching `*Payload` dataclass serialized to
  JSON (single document, on stdin or as the second argument).
- The engine returns the matching `*Result` dataclass on stdout as a
  single JSON document. Logs go to stderr as JSON Lines.

All payloads carry `schema_version: "v1"` (`STAGE_SCHEMA_VERSION`).
The engine rejects unknown versions.

All results carry `ok: bool`, `code: str` (stable machine code), and
`duration_ms: int` (inherited from `StageResult`).

## Per-stage detail

### 1. ingest

- **Input**: `source_path`, `scratch_root`.
- **Output**: `scratch_path`, `size_bytes`, `sha256`.
- **Domain**: `app/ingest/` (orchestration), `engine/ingest/` (copy).
- **Guarantees**: source file is never mutated; scratch copy is hashed
  before downstream stages consume it.

### 2. probe

- **Input**: `scratch_path`.
- **Output**: `container`, `duration_s`, `bitrate_bps`, `streams[]`.
- **Domain**: `app/metadata/` (cache + parse), `engine/media_probe/`
  (ffprobe invocation).
- **Cache**: probe results keyed by `(path, mtime, size)` in the
  `probe_cache` table (ADR-0003).

### 3. decide

- **Input**: `probe`, `is_tv`, plus a flat slice of the runtime config
  (`routing_profile`, `encode_threshold_gb`,
  `tv_encode_threshold_gb`, `allow_h264_remux_if_plex_compatible`,
  `h264_remux_max_bitrate_mbps`, `h264_remux_max_height`,
  `remux_safe_video_codecs`).
- **Output**: `route` in `{remux, encode, skip}`, `reason_code`,
  `encoder_profile`.
- **Domain**: `app/decide/`.
- **Note**: Decision is data-only; no FFmpeg args constructed here.

### 4. transcode

- **Input**: `scratch_path`, `output_path`, `decision`, video codec
  parameters, `output_container`, `extra_video_flags`,
  `timeout_seconds`.
- **Output**: `output_path`, `output_size_bytes`, `attempts[]`
  (per-attempt encoder, timestamps, exit code, log path).
- **Domain**: `app/transcode/` (attempt loop, classify), `engine/ffmpeg/`
  + `engine/transcode/` (invocation).

### 5. subtitle-convert

- **Input**: `scratch_path`, `output_path`, `keep_languages`,
  `convert_tx3g_to_srt`, `convert_bdpgs_to_srt`, BDPGS OCR tool paths.
- **Output**: `tracks_kept`, `tracks_converted`, `sidecars_written[]`,
  `review_required` + `review_reason`.
- **Domain**: `app/subtitles/`, `engine/subtitles/`.
- **Note**: OCR/conversion failure routes to review, never silent bad
  publish (`AGENTS.md §3.5`).

### 6. audio-mix

- **Input**: `scratch_path`, `output_path`, `passthrough_profile`,
  `compatible_audio_codecs`, `preferred_default_languages`.
- **Output**: `tracks_passed_through`, `tracks_transcoded`,
  `tracks_downmixed`, `default_track_language`.
- **Domain**: `app/audio/`, `engine/audio/`.

### 7. publish

- **Input**: `output_path`, `final_root`, `is_tv`,
  `create_tv_subfolder`, `deferred_publish`, `robocopy_flags`,
  `min_free_space_gb`.
- **Output**: `final_path`, `parked` (true when deferred or final root
  unsafe), `pending_publish_id`, `manifest_path`.
- **Domain**: `app/publish/`, `engine/publish/`.
- **Note**: park rather than publish when guards trip.

### 8. drain

- **Input**: `pending_publish_id`, `final_root`, `allow_overwrite`,
  `parallelism`.
- **Output**: `moved`, `skipped`, `failed`, `manifest_path`.
- **Domain**: `app/publish/` (drain), `engine/publish/`.
- **Retry policy**: 5 attempts with backoff (per ADR-0005 retry plan).

### 9. rename

- **Input**: `target_path`, `proposed_name`,
  `aggressive_episode_parsing`, `is_tv`.
- **Output**: `final_path`, `sidecars_renamed[]`, `undo_record_path`.
- **Domain**: `app/rename/`, `engine/naming/`.
- **Undo**: every apply writes an undo record; rename plan/apply/undo
  is a three-call surface.
